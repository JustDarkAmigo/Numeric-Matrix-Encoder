# Numeric-Matrix-Encoder
This repository is dedicated to a small project that encodes any integer into a QR‑like matrix. Converts a number into a customizable square grid of black/white pixels – visually similar to a QR code, but designed for numeric data. $$x^2 + y^2 = z^2$$
## Русский
Демонстрация алгоритма кодирования любого целого числа в диапозоне от $$-1 *10^9$$ до $$1 * 10^{9}$$
### Принцип работы


### Установка
1. Клонируем репозиторий
``` bash
git clone https://github.com/JustDarkAmigo/Numeric-Matrix-Encoder.git
cd Numeric-Matrix-Encoder
```
1. Установка зависимостей
``` bash
pip install -r requirements.txt
```
### Запуск
1. Откройте файл main.py
2. Выберете режим работы в функции

3. запустите файл

``` bash
python main.py
```
